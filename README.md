# Eating Animation (Horizon native mod)

![Eating animation Icon](icons/eatinganimation.png)

It is a port of [Eating Animation](https://github.com/Theoness1/EatingAnimation) for Horizon.

While you eat food, or drink a potion or milk, the item in your hand shows its bitten frames.

The frames come from a resource pack you build from your own copy of the EatingAnimation download with `tools/make_frame_pack.py`, and drop into Horizon's `resourcepacks/` folder.
~~Or you can just download it from Releases...~~

![Eating animation preview](icons/eatinganimation.gif)

## Build

```sh
horizon-launcher native-build . --trust-native-code
```
